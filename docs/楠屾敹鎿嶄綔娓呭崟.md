# 见微注意实验室 · 人工验收清单（v1）

本表只供开发与测试，**不代表已通过实际设备和正式后台验收**。

## 必须由你亲自做的四项

1. 从 `js/config.js` 中填写通过老师 `/hw2` 创建的6位项目码。下载密钥仅自己保存，千万不要交给代码仓库。
2. 在实际Windows电脑上开启摄像头，按9点（每点5次）训练，再看5点验证数据。误差过高的行为应能选择重新校准／低质量继续／鼠标模式；退出后摄像头应停止。
3. 用测试编号 `01` 在三个实验各完成一次20次，老师后台能看到三个 `test_` 实验且CSV行数各20。注意每个字段名称、类型、空值、完整性与上传`warnings`。
4. 你确认README的研究假设、可接受的场景与指导语，**收数前完成Git提交**。部署GitHub Pages后从真实公开网址再做一次完整测试。

## 每个实验的正式细节

**地图（20次）**：A组北向主图＋航向小图；B组反过来。相对方向10次（左右），世界方位10次（东南西北），各任务前2次练习；题目保持显示到按键，6秒超时。两种显示组应按实际人数5:5分配。同一题卡的地图、地标、车头和目标一致，仅主次显示不同。

**变化盲（20次）**：有提示10次，无提示10次；每类别4张场景中，各2张有提示；不同被试交叉平衡；练习2次。240/80/240/80ms，先空格再点击目标，30秒超时，超时与错误点击都记录。

**PCP（20次）**：A组原版雷达图，B组增强型颜色/标签雷达图；整体判断10次，局部判断10次；每任务前2次练习，6秒超时。颜色不应随正常/异常变化，局部判断需只考虑指定指标。两组6项指标取值应匹配。
