# 见微 · 注意实验室（Attention Lab）

北京师范大学工程心理学 W5–W8 · 作业二「复现＋改进」项目。

> **当前阶段：v1.0.0-rc1，供本人审查与技术测试。尚未采集真实被试数据。**
>
> 2026年11月8日开发草案。最终实验设计、事前预测与数据解释由项目提交人审阅确认；禁止将自动化测试数据当作真实被试数据。即便界面已出现“结果页”，也不代表获得了研究结论。

## 一、项目概览

本项目使用 HTML + CSS + 原生 JavaScript 与 Canvas 绘制，可直接双击仓库根目录的 `index.html` 运行实验。无需 Node、数据库或自行部署服务端。一个前端程序提供三个独立经典实验的复现与改进，并通过老师 `/hw2` 平台提供的后台接口收集匿名试次。

| 模块 | 课程及依据 | 改进及条件 | 单人正式试次 | 练习 |
|---|---|---|---:|---:|
| 变化盲 `change` | W5，Rensink et al. (1997) | 有效物体类别提示/无提示；相同闪烁时序、20张不同场景 | 20（10＋10，被试内） | 2 |
| PCP 显示 `pcp` | W6，Wickens & Andre (1990); Wickens & Carswell (1995) | A组原版统一标识雷达图；B组增强雷达图；各做整体、局部两类判断 | 20（任务各10） | 每任务2，共4 |
| 地图朝向 `map` | W8，Aretz (1991); Tlauka, Stanton & McKenna (2000) | A组北向主图/航向小图；B组航向主图/北向小图；两类参照系判断 | 20（任务各10） | 每任务2，共4 |

**正式被试计划：** 10位其他被试，每个实验分别计数。地图及PCP各两组，每组目标5人；变化盲每人完成两条件。采用已完成记录数量动态偏向人数少的一组；后台不可读时，使用01–10匿名编号的单双数预分配。分组决定后保存于参与者当前浏览器。跨设备同时打开网站、半途退出、同一编号重复提交仍可能破坏精确5:5，正式收数需在后台核验并人工纠正，不应声称系统能够原子性锁组。

## 二、设计与可检验的事前预测（**正式收数前必须由本人确认和留下Git提交记录**）

### W5 变化盲
- **自变量**：任务相关物体类别提示 vs 中性无提示，均呈现同样时长的提示页（1.3s）。
- **因变量**：变化位置判断正确率（包括错误点击、未响应）、正确检测的首次空格反应时（ms）、超时比例。记录首次发现与最终点击时间、场景标识、目标类别和位置、提示类别、鼠标/眼动轨迹。
- **控制**：图A 240ms→空白80ms→图B 240ms→空白80ms循环；每张最多30s。20张场景每人不重复，每类物体4张；每类均分2张提示与2张无提示。不同被试按编号平衡每张场景的提示与否。变化位置只在点击后揭示。
- **事前预测 H1**：有效类别提示将提高变化位置判断正确率，缩短正确试次检测反应时。
- **分析**：计算每位被试有/无提示的正确率、平均/中位正确RT差值（无提示−提示），配对图、置信区间（样本足够时）、报告超时与错误。还需检查刺激类别及场景难度。
- **限制**：类别线索与场景内多个项目相关，提示并不指明位置。当前原创场景属于课程级复刻，未完全使用原论文图片；结论不可直接视为原论文的精确重复。

### W6 PCP 显示
- **自变量**：A组原版雷达图 vs B组带固定颜色和标签的增强雷达图（被试间）。任务类型：整体判断 vs 局部判断（同一被试均完成10次）。
- **因变量**：各任务下的准确率、正确反应时；两组在相同任务下的差异及「显示方式×任务类型」方向。
- **操作**：6项标准化生命体征；整体任务6项均在0.78–1.20范围内按J，否则按F；局部任务只检查被指名指标是否高于1.20，超过按F，否则按J，其他指标与答案无关。
- **事前预测 H2a**：增强编码更利于局部判断（改善准确率/缩短RT）。
- **事前预测 H2b**：增强编码可能牺牲整体判断的整合优势（不保证方向）；检验局部收益与整体代价的权衡。
- **控制**：A/B两组看到按同一固定种子生成的指标取值；增强版只增加固定、不依当前正确答案变化的颜色/标注；不能以红色直接亮出异常答案；练习、键位和时限相同。
- **限制**：原版「整体是否全部正常」也可用逐项搜索完成，并非纯粹的多维整合判断；两组各5人，统计效力有限，需谨慎解释。

### W8 地图朝向
- **自变量**：A组北向上大地图＋航向上小地图；B组航向上大地图＋北向上小地图（被试间）。任务类型：车头左右 vs 地理东南西北（被试内）。
- **因变量**：各任务下正确率、正确RT；探索性眼动在主/副地图AOI的注视数量。两种任务的选项数不同，**只在相同任务内比较组别**。
- **任务1（ego）**：红点位于蓝色车辆车头左边（←）还是右边（→）？
- **任务2（world）**：红点位于车辆位置的哪个地理方向（↑北、→东、↓南、←西）？
- **事前预测 H3a**：航向大主图的相对方向判断可能更快；
- **事前预测 H3b**：北向大主图的世界中心方位判断可能更快。
- **控制**：两个组使用相同种子道路网、车辆朝向、地标和目标题；仅改变主副地图的视觉大小与方向。地图直至作答始终显示，避免附加空间记忆负荷。
- **限制**：本项目只比较两种双地图布局；老师的原版单地图及原论文对照，需要课堂原版有效数据才能额外展示。不可将两种新布局直接称为已证明优于原版。

## 三、研究流程与指导语

每个实验均遵循：匿名编号与知情同意 → 选择注视模式 → （可选）九点校准＋五点验证 → 总指导语 → 每项任务分段指导语 → 练习试次（正确答案反馈） → 正式试次（进度/错误反馈） → 个人结果页 → 数据提交状态 → 匿名汇总/模型对照。

- 地图练习共4次，PCP练习共4次；两个任务块的顺序根据编号平衡。正式分别20次。每试次最长6秒；刺激前地图350ms注视十字、PCP400ms。
- 变化盲练习2次，正式20次；每次最多30秒，采用空格报告发现＋鼠标点击定位；正式试次之间交错有/无提示，以相同1.3秒提示显示时长控制准备过程；正式结果不提前显示理论效应。
- `performance.now()`计时；视觉帧按绝对时钟计算，浏览器后台失焦会被记录；移动端虽可查看，但推荐桌面浏览器和键盘完成正式数据。

### 九点校准、五点验证

- 9个点，每点要求注视并点击5次（45次）。前端调用 `webgazer.recordScreenPosition` 训练。
- 5个验证点无需点击，每点注视1.8秒，忽略前600ms，用预测点到实际点的距离中位数估计误差；平均误差≤200px且有效验证点≥3才判定通过。
- 显示误差、有效点数、估计频率；未通过可重新校准、接受低质量标记或改用鼠标/模糊揭示。
- 模式记录在逐试次数据中，**鼠标/模糊揭示轨迹不得混同摄像头眼动**。眼动坐标在Canvas上归一化采样，稀疏上传以满足256KB上限；不是原始视频。
- **真实摄像头与WebGazer运行效果尚未做设备验证，必须由使用者测试，不能以此说明所有加分已经实现并验收。**

## 五、数据核验与分析约定

- 每个实验正式被试≥5人，目标10人；每组/每任务合计至少10条试次（实际目标每组5人×10次＝50条）。
- 每条记录包括 `task`、`stimulus_id`、`correct`、`response`、`answer`、`rt_ms`、`timeout`、`trial_index`、`group`、`mode`、眼动/鼠标稀疏轨迹和实验专属变量。试次字段不超过40个；轨迹数组不超过500项；单次提交≤256KB。
- 注意：每人做地图与PCP各20次，但每个显示×任务组合中的每人只有10次；由于两个组不同，同一人不需要体验另一组显示。这对应用户最终确定的两组设计。
- 在「数据中心」计算同条件平均RT、正确率、人数/试次数，变化盲提供按被试配对的有/无提示差值；理论图仅为方向示意，未采集数据时不显示伪造实测。
- 全班原版数据如果能经授权获取，在「数据中心」导入CSV；**必须确认变量、统计口径、实验版本与刺激可比**，否则只进行定性对照并说明不可比性。内置理论图不能替代这项加分。
- 统计解释由项目提交人最终决定。必要时可对每位被试的条件均值做效应量与不确定性区间，不把25/50个重复试次当作25/50名独立被试。
